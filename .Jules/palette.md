## 2024-06-24 - Focus States on Custom Elements

**Learning:** Custom UI elements like GlassButton frequently omit standard keyboard focus outlines, negatively impacting accessibility for users who rely on keyboard navigation.
**Action:** Standardize the inclusion of Tailwind's `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2` classes on all interactive components to ensure consistent keyboard focus visibility.
