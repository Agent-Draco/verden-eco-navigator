## 2026-04-22 - GlassButton Keyboard Accessibility

**Learning:** Custom interactive elements (like div-based or framer-motion wrapped buttons) often lack native browser focus rings. Using explicit focus-visible classes ensures robust keyboard navigation.
**Action:** Add `focus-visible:ring-2 focus-visible:ring-primary focus-visible:ring-offset-2` to all custom button and interactive wrapper components to maintain accessibility standards without compromising visual aesthetics.
