## 2026-07-01 - Semantic Navigation Indicators
**Learning:** When standardizing navigation components (like Sidebars or BottomNavs), using `aria-current="page"` and keyboard focus indicators (`focus-visible`) is essential to maintain screen-reader accessibility alongside visual active states.
**Action:** Ensure all active routes in future navigation components utilize semantic ARIA states and proper Tailwind `focus-visible` utility patterns.
