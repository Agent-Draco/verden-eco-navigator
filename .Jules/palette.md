## 2026-06-19 - Standardize Focus States and ARIA in Nav Components
**Learning:** Custom interactive elements like GlassButton and Nav bars often miss standard focus indicators and screen-reader context (like aria-current) compared to native inputs, negatively impacting keyboard accessibility.
**Action:** Applied standard `focus-visible` utility classes and semantic ARIA states (`aria-current="page"`) to ensure consistent, accessible navigation across custom UI components.
