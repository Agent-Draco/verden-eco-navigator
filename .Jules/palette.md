## 2024-05-24 - Add accessibility attributes to icon-only toggle buttons
**Learning:** Icon-only toggle buttons (like password visibility) require `aria-label`, `aria-pressed`, `type="button"`, and `aria-hidden="true"` on inner decorative icons to be accessible for screen readers, as well as distinct `focus-visible` styles for keyboard navigation.
**Action:** Future icon-only interactive elements will include these comprehensive accessibility and focus-state enhancements.
