## 2026-05-20 - GlassButton Accessibility States\n**Learning:** Custom Framer Motion `GlassButton` components mapped complex Tailwind transition and cubic-bezier easing values to the `base` styles, but omitted crucial native HTML button interaction states like `focus-visible` rings and `disabled:opacity-50` visual treatments, reducing screen reader and keyboard navigation clarity. Additionally, Framer Motion's `whileTap` animations continued to trigger on `disabled` properties natively passed via `HTMLMotionProps` unless explicitly intercepted and conditionally turned off based on the `props.disabled` state.\n**Action:** When creating or evaluating future interactive UI primitives, prioritize mapping `disabled` prop inheritance and explicitly implement robust `focus-visible` utility classes to uphold base accessibility standards.
