## 2024-05-24 - [Navigation Accessibility Polish]
**Learning:** Adding visible focus rings and ARIA current states to main navigation elements improves accessibility for screen reader and keyboard users. Using `group-focus-visible` can solve issues where tooltips or labels are only visible on hover, which locks out keyboard-only users.
**Action:** Always test navigation elements for keyboard interactivity and ensure they visually and programmatically indicate their active and focused states.
