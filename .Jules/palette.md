## 2025-01-01 - Enhance Tooltip Keyboard Accessibility
**Learning:** Custom tooltips that rely solely on `group-hover:opacity-100` are invisible to keyboard navigators. They must always be paired with `group-focus-visible:opacity-100` and the parent element requires a visual focus indicator (`focus-visible` styles) to maintain full keyboard accessibility. Furthermore, visually hidden text used for tooltip effect may not be properly announced by screen readers if opacity is 0, so assigning explicit `aria-label` to the parent button and hiding children is more robust.
**Action:** Always add `group-focus-visible:opacity-100` to custom tooltip classes and explicitly ensure all icon buttons have an `aria-label` with `aria-hidden="true"` applied to their children to avoid double reading.
